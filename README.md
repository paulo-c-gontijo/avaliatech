# AvaliaTech

Aplicativo Flutter de avaliação formativa. Implementação em desenvolvimento baseada nos documentos de classes, fluxos e telas fornecidos pelo autor.

## Regra central
Questionário é conteúdo reutilizável; publicação é uma aplicação independente com turmas, datas, limite de tentativas e resultados próprios. O questionário pode ser criado sem publicação e reutilizado quantas vezes forem necessárias.

## Desenvolvimento
Execute `flutter pub get`, `flutter analyze`, `flutter test` e `flutter run` com o SDK Flutter instalado. A interface e o domínio serão implementados na branch `feature/flutter-avaliatech`.

## Estado
A implementação está em andamento. Ainda não há backend de produção nem autenticação institucional. Não utilizar dados reais de alunos antes da configuração de segurança e persistência apropriadas.
